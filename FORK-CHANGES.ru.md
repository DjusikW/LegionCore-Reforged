# Изменения форка DjusikW

[English](FORK-CHANGES.md) | **Русский**

Форк [Titans-Project/LegionCore-Reforged](https://github.com/Titans-Project/LegionCore-Reforged) для домашнего некоммерческого сервера WoW Legion 7.3.5. Ветка `djusikw/main` = апстрим `main` + правки ниже. Общие исправления по возможности отправляются в апстрим как pull request.

Участники: DjusikW, Claude (Anthropic) — соавтор коммитов.

Статусы: **проверено** — проверено в игре; **собрано** — собирается без ошибок, в игре не проверено или проверено частично.

## Ядро

| Изменение | Статус |
|---|---|
| Существа класса «разбойник» получают полосу энергии. Раньше энергия у существ всегда была 0, и боссы с фазами по энергии (Низендра, Элерета Ренферал, Кенарий, Драконы Кошмара и др.) застревали в первой фазе. | проверено частично: у Низендры энергия есть, «Заразное дыхание» применяется |
| Автобаланс подземелий и рейдов под число игроков, модуль `modules/mod-autobalance` (AGPL-3.0-or-later; `AutoBalance.*` в `autobalance.conf`, по умолчанию выключен), видимая аура 900100 «Автобаланс» (`modules/mod-autobalance/sql/hotfixes`). Хуки ядра: `UnitScript`, `Creature::SetStatModifiers`. | собрано |
| Личная прогрессия по дополнениям, модуль `modules/mod-individual-progression` (AGPL-3.0-or-later; `individual-progression.conf`, README в модуле): у каждого персонажа свой этап (0–3 Классика … 60–65 Легион, тиры рейдов по порядку выхода), предел уровня по дополнению, последний босс тира переводит группу дальше, подземелья / рейды / материки / зоны / вводные задания следующих этапов закрыты (и в поиске группы), рыцарь смерти / охотник на демонов / союзные расы открываются по этапу, аккаунты ботов исключены, `.progression show/set`. Хуки ядра: `PlayerScript::OnCreatureDeath`, `OnInstanceBossDone`, `CanEnterMap` (и в блокировках поиска группы), `CanTakeQuest`, `CanCreateCharacter`; `GiveXP` прекращается, если скрипт забрал опыт. | проверено частично: этап, предел уровня и команды проверены в игре |
| Боты-игроки: система модулей (`modules/<имя>` со своим `.conf`), сессии ботов без клиента, `PlayerScript::OnWhisper`, доступ к LFG, броскам лута и голосованию за кик (9 коммитов из [DemonCore](https://github.com/DemonCore-Legion/DemonCore)) и модуль [DemonCore-Playerbots](https://github.com/DemonCore-Legion/DemonCore-Playerbots) `ab4f4b1` в `modules/mod-playerbots` (`playerbots.conf`, `.playerbots create <класс> [спек]`). | собрано |
